The No Man's Sky Retro Installer is a fan-made application created to facilitate the installation of older versions of the game No Man's Sky. This application is intended for use by individuals who wish to experience older versions of the game and is not affiliated with the game's developers or publishers.

This application does not contain any game data, and only serves as a tool to download the game from Steam. The user must have a valid, purchased copy of the game and provide their own Steam account details to use this application. Your Steam credentials are sent to Steam and to nobody else, and are never written to disk.

The removal of DRM measures in the application is done solely for the purpose of allowing the older version of the game to function and is not intended to encourage or support piracy. The creators of the application do not condone or support piracy, and users are reminded that it is illegal to distribute or use pirated software.

The following third-party work is used in the No Man's Sky Retro Installer:

SteamKit2 by the SteamRE team - https://github.com/SteamRE/SteamKit
LICENSE: GNU Lesser General Public License v2.1
- Speaks Steam's protocol: sign-in, depot keys and the content servers the game is downloaded from.

DepotDownloader by the SteamRE team - https://github.com/SteamRE/DepotDownloader
LICENSE: GNU General Public License v2.0
- The installer's own depot download is derived from it, which is why this installer is GPL.

steam_api64.retro by Qjimbo - https://github.com/NoMansSkyRetro/steam_api64.retro
LICENSE: MIT License
- Replaces steam_api64.dll so these builds run without the Steam client, unwrapping the SteamStub
  DRM in memory as the game loads. It contains no code from either project below, but its
  SteamStub handling follows Steamless by atom0s (https://github.com/atom0s/Steamless) and its
  Steamworks interface layout follows the Goldberg Steam Emulator by Mr_Goldberg
  (https://gitlab.com/Mr_Goldberg/goldberg_emulator).

RetroShaderFix by EthanRDoesMC - https://github.com/EthanRDoesMC/RetroShaderFix
- The shader packs that fix the older builds against current graphics drivers, applied
  automatically during the install and bundled as a standalone tool in the Extras folder.
